
# Erased Tapes

This project is part of the Web Development II Clone Tasks practice.

## About the Project

The aim of this project is to recreate the Erased Tapes webpage using React and CSS, following the provided wireframe and design requirements.

The webpage includes a header, navigation links, an article, an album gallery, an author section, comments and a footer.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## Project Structure

The main application is written in `App.jsx`.

The website styles are defined in `App.css`, while `index.css` contains the basic global settings.

Images and icons are stored in the `src/assets` folder.

## Responsive Design

The webpage uses CSS Grid, Flexbox and Media Queries to adjust its layout for different screen sizes.

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal inside the project folder.
3. Run `npm install` to install the dependencies.
4. Run `npm run dev` to start the development server.
5. Open the local address displayed in the terminal.
