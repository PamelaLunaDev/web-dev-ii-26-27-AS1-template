
# watch.it

This project is part of the Web Development II Clone Tasks practice.

## About the Project

The aim of this project is to recreate the watch.it movie webpage using React and CSS, following the provided responsive wireframes and design requirements.

The webpage includes a header, navigation links, a search button, six movie posters, movie descriptions and WATCH NOW buttons.

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## Project Structure

The main application is written in `App.jsx`.

The website styles are defined in `App.css`, while `index.css` contains the basic global settings, fonts and colours.

The movie poster images are stored in the `src/images` folder.

## Responsive Design

The webpage uses CSS Grid, Flexbox and Media Queries to adjust its layout for different screen sizes.

- Desktop: Featured movie card, two-column layout and horizontal movie cards.
- Tablet: Two-column layout with vertical movie cards.
- Mobile: Single-column layout with vertically stacked movie cards.

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal inside the project folder.
3. Run `npm install` to install the dependencies.
4. Run `npm run dev` to start the development server.
5. Open the local address displayed in the terminal.
